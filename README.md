# Kosmetická rutina ✨

Každé pondělí v 7:00 se tu automaticky založí nové issue s týdenním checklistem
(`checklist.md`) a minulý týden se zavře. Odškrtává se přímo v issue – na webu i v mobilní aplikaci GitHub.

- **Upravit kroky:** edituj `checklist.md`
- **Spustit hned:** Actions → „Týdenní checklist kosmetické rutiny“ → Run workflow
- **Historie:** Issues → filtr `label:rutina` → Closed
